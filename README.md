# Conference Attendee Check-in Monitoring System

ASP.NET Core MVC laboratory exercise implementation.

## Features
- User registration and cookie authentication
- Login/logout
- Attendee registration
- Monitoring list
- Edit/details
- Check-out
- Search
- Validation
- Repository pattern using static Lists
- Bootstrap UI

## Run
1. Open the `.csproj` in Visual Studio 2022.
2. Restore/build the project.
3. Run with HTTPS.
4. Register a staff account, then log in.
5. Add attendees and test monitoring/check-out/search.

## Important
This project uses in-memory static Lists as required by the specification and does not use a database.
